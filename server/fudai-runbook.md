# 拼多多百亿消费券福袋 · 每日抢券手册（2026-10-22 实战定版）

目标：拼多多「百亿补贴 → 百亿消费券」页面的三个消费券福袋全部抽到手。
活动期 2026-10-16 – 11-13，每日 0 点刷新福袋。抽中券约 24 小时有效。

## 环境与铁律

- 工具都在 `~/workspace/muse-android-shell/server/`：`phone.py call <tool> '<json>'`。
- **看图首选手机本机 OCR（图不出手机、整帧约 2 秒、坐标即真实屏像素、无需换算）**：
  `shell` 工具跑 `SFID=$(dumpsys SurfaceFlinger --display-id | grep MuseScreen | grep -oE 'Display [0-9]+' | grep -oE '[0-9]+')`
  取当前虚拟屏的 SurfaceFlinger ID（每次建屏都会变，必须现查），
  `screencap -d $SFID -p /sdcard/MuseShell/frame.png`，再
  `linux.exec` 跑 `python3 /root/muse_ocr.py /mnt/sdcard/MuseShell/frame.png`
  （脚本在手机 Debian 容器里，输出 JSON：items=[文, cx, cy]）。
  备用（容器不可用时）：`see_parts.py vscreen <out.jpg> 32000` 切片取帧回沙盒 +
  `./ocr-venv/bin/python ocrtap.py file <图>`（屏坐标 = 图坐标 / scale）。
- 全程只在**虚拟屏**（1080×2376@480，逻辑宽 360dp）里操作，**绝不碰主屏**：a11y.* 的手势只落主屏，禁用；
  只用 vscreen.* 与 shell 工具。
- 不下单、不付款、不点商品购买按钮。抽券之外不点任何商品卡（奖励商品页只用左上角箭头返回）。

## 流程

1. `phone.py call status '{}'` 确认壳在线（version ≥0.6.6）；失败等 60 秒重试一次，再失败报错退出。
2. 解锁：`phone.py call lock.unlock '{}'`（零参数，PIN 在手机端；未锁自动跳过）。
3. `vscreen.create {"width":1080,"height":2376,"dpi":480}`（已存在会报错，忽略），
   `vscreen.launch {"package":"com.xunmeng.pinduoduo"}`，等 6 秒。
4. 进消费券页：取帧 OCR 找「百亿」点入专区（中途弹免费礼物窗就点右上 × 关掉，
   坐标每帧现算）；专区页 OCR 找「百亿消费券」条点入。页面标题出现「消费券」、
   能看到「消费券福袋 10.16-11.13」字样即到位。
5. 看三袋状态（袋行按钮文案）：
   - 「去使用」= 已抽到，跳过。
   - 「立即抽福袋」= 直接点 → 结果弹窗点「开心收下」（约在屏 (540,1737) 附近，每帧 OCR 定）。
   - 「邀好友抽福袋」或「抽福袋」（需组队）= 走第 6 步加入循环，成功后袋位翻成「立即抽福袋」再抽。
   - 「抽N个后开启」= 前面的袋抽完自然开启，回头再看。
6. **抢码加入（核心，拼速度）**：每轮 ≤6 次尝试：
   ```
   R=$(curl -s "http://bz.5138zhuan.com/api.php?action=onekey")   # 404=池空，隔 5–10 秒重试
   NUM=<R 里的 number>
   phone.py call shell '{"cmd":"am start --display <显示屏ID> -a android.intent.action.VIEW -d \"pinduoduo://com.xunmeng.pinduoduo/search_result.html?search_key=<NUM>\""}'
   sleep 4
   vscreen.tap (540,1400)   # 「立即加入抽福袋」实测坐标（2026-10-27 本机 OCR 实测，见已知坑）
   sleep 3，取帧验收（本机 OCR 约 2 秒，验收必须做）；未生效再补点一次，不要预先连点两次
   ```
   - **验收时若弹窗还开着**（袋位没变、OCR 还能看到「立即加入抽福袋」）：直接用该帧 OCR
     测得的按钮坐标点它，并把实测坐标回填本手册（盲点值以实测为准）。
   - 失败长相：回到消费券页、袋位没变（码被别人先占，拼多多只闪小字 toast，截图看不见）→ 下一轮。
   - 成功长相：袋位翻成「立即抽福袋」（可能伴随己方队伍弹窗开着，先点 × 关掉再抽）。
   - **深链接发出前，拼多多必须停在消费券活动页**：若当前是福袋奖励商品页（标题「消费券抽福袋奖励」），
     先点左上返回箭头退到活动页再发，否则链接被吞、白白浪费码。
7. 三袋都抽完后，点福袋区右上「奖励」打开奖励记录，核对今日新增券
   （按到期时间 ~23:xx 的就是今天的；记下折扣、最高减、到期）。
8. **顺带点亮 5 折星星（2026-10-28 用户定，抢完福袋必做，在消费券页上起步）**：
   消费券页顶部有「限时翻倍 5 折 · 8 天内再点亮 N 次必得」条：一排 6 颗星 +
   右侧「立即点亮」按钮，每天可点亮 1 次，集满必得一张 5 折消费券。
   （2026-10-28 截图状态：已亮 1 颗、还差 5 次，窗口约到 2026-11-05；
   若每日不断，2026-11-01 前后集满。）
   - **点亮不是点一下就行（2026-10-28 用户纠正）**：点「立即点亮」后会进入
     浏览任务——要滑动屏幕预览商品满要求时长（10 秒或 30 秒，以页面倒计时/
     任务文案为准；看不清要求时按 35 秒执行），时长达标才算点亮成功。
   - 流程：本页 OCR 定位「立即点亮」点它（**2026-10-28 首跑实测坐标 (902,434)**）。
     **实测为两段**：①福袋抽完后按钮会变「解锁点亮」——点它弹「如何解锁点亮？」
     框，点框内「去首页」(539,1466)，再按 首页→百亿补贴→百亿消费券 路径重进
     本页，按钮即恢复「立即点亮」（首页商品流滑动不计点亮时长，别在首页刷）。
     ②点「立即点亮」后本页顶部出现横幅「滑动浏览当前页面10秒即可点亮」带
     倒计时，在**本页商品流**慢速上滑（每 2~3 秒一次），倒计时 10→0、横幅
     消失即达标；回页顶验收：文案变「再点亮 N-1 次必得」、按钮变「今日已点亮」。
     2026-10-28 实测：已亮 1→2 颗，还差 4 次。
   - 若按钮已是已点亮态/今日已点过（用户可能手动点过）→ 视为已完成，记日志即可。
   - 若星星条已消失或提示券已发放 → 集满收官，核对奖励记录里是否多了一张
     5 折券（计入今日真 5 折报喜），此后本步自动跳过。
   - 找不到点亮条、浏览达标仍未点亮 → 记为点亮失败，汇报时带一句
     （不影响福袋口径）。
9. **顺带做百亿补贴会员打卡（2026-10-26 用户定，抢完福袋必做）**：
   回到百亿补贴专区页 → 点右上角「会员」进「百亿补贴会员」页 → 找「打卡送积分」
   的一周打卡条 → 当天格子上的按钮文案就是「打卡」（红色）时点它 →
   取帧验收：该格变灰/按钮消失、高亮移到下一天的「待打卡」，即打卡成功（+10 积分）。
   - 若没有任何格子是「打卡」（今天已打过，如用户手动打过）→ 视为已完成，记日志即可。
     （2026-10-26 实测形态：周一第 1 天格金币带红勾 = 今日已打；高亮黑金币格是下一天、
     标「待打卡」，点它无反应，不要误当今日格反复点。）
   - 找不到会员入口或点后未生效 → 记为打卡失败，汇报时带一句（不影响福袋本身的口径）。
10. 收尾：`vscreen.close {}`。

## 汇报口径

- 今日券里出现**真 5 折券**（以抽中弹窗/奖励记录为准，袋面标注的 5 折不算）→ 回主聊天报喜，
  附今日全部券清单。点亮集满发放的 5 折券同样算真 5 折（以奖励记录到账为准）。
- 整场失败（壳离线、解锁失败、页面结构大变、6 轮全被抢）→ 回主聊天简报失败环节。
- 其他情况（领到 7/7.5/8 折等）→ 静默，只把结果记进当日日志。

## 已知坑

- 码的时效以秒计：拿码后禁止先截图/OCR，顺序必须是 onekey → am start → 4 秒 → 盲点。
- 加入弹窗按钮对注入点按迟钝，所以盲点两次；但弹窗已关后多余的点会落到页面上，
  两次为止，不要连点更多。
- onekey 返回的码是全码（9 位）；`action=get&count=8` 是列表接口，onekey 更直接。
- 每次 compose/页面改版都可能让坐标漂移：旧盲点 (360,783) 是 720×1280@320 屏上的实测值；
  2026-10-26 统一改 1080×2376@480 后，盲点按比例换算为 (540,1453)。**2026-10-26 14:00 首跑实测有效**：
  三袋加入均靠盲点第一下生效（袋1/袋3 各 1 轮、袋2 第 2 轮成功）。副作用实测：加入成功后页面很快回到
  活动页，第二下盲点会落到袋位「去使用」上打开奖励商品页（无害，点左上箭头 (55,190) 即回活动页，
  但回页后要重新 OCR 确认袋序——袋位会按状态重排，未抽的排最左）。另：抽中弹窗点「开心收下」(541,1634)
  实测会直接打开该券的奖励商品页（不是单纯关弹窗），同样左上箭头返回即可，券已入账不受影响。
  运行中手机多次息屏锁定（约每 3 分钟一次），取帧只剩时钟/日期时先 `lock.unlock` 再继续，勿误判页面。
- **2026-10-27 实测订正**：加入弹窗「立即加入抽福袋」按钮实测在 **(540,1400)**，单点一次即生效
  （袋2/袋3 各 1 轮成功）；旧盲点 (540,1453) 落在按钮下方，连点两下会多开一层我方队伍的
  「邀请好友抽福袋」弹窗（栈式叠加，后一层会残留并在关奖记录/回页时重现），关法 = 点弹窗右上
  × **(990,800)**（须在解锁状态下点；BACK 对该层不稳定）。另：拼多多冷启动可能直达「限时秒杀」
  页而非首页，`am force-stop` 后重拉即回真首页。
